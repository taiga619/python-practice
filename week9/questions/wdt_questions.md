# WDT 仕様書への質問リスト

## 質問1: KICK に 0x5A5A 以外を書いたとき
WDT の KICK(0x08)の説明についての質問です。
説明欄には0x5A5A を書くと、カウンタが TIMEOUT の値に戻ると記載がありますが、KICKに所定の値以外を書いた場合はどういった動作になるのでしょうか。
自身は、書き込みは無視され、a.カウンタは戻らない(何も起きない) or b.STATUS などに、エラーが記録される
のどちらかで、aだと予想しています。実際はどうなるのでしょうか？

- 型: ④ 想定外の入力
- 知りたい理由:テストの際に、0x5A5A以外を記載した場合の期待動作を確認したいため


## 質問2: CTRL の Reserved の扱い
WDTのCTRLのbit表にある、Reservedについて質問です。
このレジスタには属性が記載されていません。
一方で、STATUSのReservedにはROと記載されています。
この場合、CTRLのReservedの属性は何になるのでしょうか？
自身は、STATUSと同様にROになると考えています。
STATUSと同様にRO or RW どちらになるのでしょうか？
- 型: ⑨ Reserved の扱い
- 知りたい理由: CTRLに書くとき、Reservedに何を書けばいいか決められないため

## 質問3: TIMEOUT に 0 を書いたとき
WDTのTIMEOUTの項について質問です。
説明に、「タイムアウトまでの時間を設定する。単位は、カウント。」と記載がありますが、特に0を記載した場合の動きが記載されておりません。
最小値は1で、0を書くとすぐタイムアウトすると考えています。
実際は、a.すぐタイムアウトする、b.無視され、以前の値を保持する
のどちらになるのでしょうか？

- 型: ③境界の扱い
- 知りたい理由:タイムアウト時間を適切に設定するために必要なため
